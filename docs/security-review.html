安全评审报告

对 docgate 0.1.0 代码的 STRIDE 逐面评审。范围：HTTP 接口、认证、路径处理、配置与凭证存储、审计日志。评审方式为通读实际代码，每条发现给出定位、利用场景与处置。

发现与处置

本次评审共 4 个需处置的发现（1 个中危、3 个低危），全部已修复或加固；另有 5 项残余风险接受并记录。

M1 · 完整模式 iframe 无法携带凭证，沙箱页面实际加载失败 中 · 已修复

类别信息泄露 / 设计偏差（Spoofing 与可用性交叉）
定位docgate/server.py 路由 /api/v1/rawhtml（曾要求 Bearer 认证）
场景沙箱 iframe 由浏览器导航加载，无法携带 Authorization 头，请求必然 401——完整模式渲染的其实是一段 JSON 错误页。更糟的是修复方向若选错（把长期 token 放进 URL），会把凭证泄漏到浏览器历史与日志。
处置一次性 ticket 即该端点的唯一凭证：只能由持 token 的调用方换取（html-ticket 仍要求 Bearer），30 秒过期、单次使用、绑定文件路径；无效 ticket 计入限速与审计。网络层断言已加入浏览器冒烟测试（沙箱请求真实返回 HTTP 200 文档）。ticket 无法爆破（192 位随机）。

L1 · 来源键可伪造（直连暴露时绕过按 IP 限速）低 · 已加固

类别欺骗（Spoofing）
定位docgate/server.py client_key()
场景若服务被误配为公网直连（--host 0.0.0.0），攻击者可轮换伪造的 Cf-Connecting-Ip 绕过按来源的失败限速，并向审计日志灌入假来源。
处置信任边界是回环 + 隧道（部署手册明确禁止公网直连；隧道场景该头由 Cloudflare 边缘覆写，无法伪造）。已加固：来源键截断至 64 字符防日志与限速表污染。残余风险：256 位 token 本身不可爆破，限速只是纵深防御；如需更强保证，在 Cloudflare Access 后再加一层（部署手册第六节）。

L2 · 慢速连接可占用工作线程 低 · 已修复

类别拒绝服务（DoS）
定位docgate/server.py DocgateHandler
场景不发完整请求的慢连接（slowloris）长时间占住线程。
处置处理器套接字超时 30 秒；URL 长度上限 4096；不读取请求体；线程为守护线程。

L3 · 大文件整块读入内存 低 · 已修复

类别拒绝服务（DoS）
定位docgate/server.py _api_raw()（曾 fh.read()）
场景发布目录内出现超大 PDF/图片时，一次请求把整个文件读进内存，多请求并发可耗尽内存。
处置改为按 64 KB 分块流式发送，Content-Length 取自文件大小。

已确认的防护（逐项验证）

STRIDE 面防护证据
欺骗token 哈希存储 + 常数时间比较；错/缺 token 一律 401；连续失败封禁47 项单测含 401/429 矩阵
篡改无写入端点；方法白名单 GET/HEAD，WebDAV 动词 405；请求体不消费单测覆盖 9 种写入动词
抵赖JSONL 审计：认证失败、ticket 拒绝、文件访问（含来源、根、路径）；凭证永不入日志~/.local/state/docgate/audit.log
信息泄露用户内容永不以 text/html 返回（完整模式除外，强制 CSP sandbox 无 allow-same-origin）；路径沙箱（realpath 包含性、符号链接逃逸拒绝、隐藏文件跳过、扩展名白名单）；错误响应不含栈与本地路径单测 + 实测（../、.git、越界符号链接均 404）
拒绝服务限速封禁、URL 上限、渲染体积上限、线程超时、流式发送见 L2/L3 处置
权限提升只读设计天然无提权面；服务以普通用户身份跑 systemd 用户服务，绑定 127.0.0.1部署手册安全清单

已知残余风险（接受并记录）

  • 发布目录内容可见性：非隐藏的敏感文件（如手写密码的 yaml）对持 token 者可见。缓解：--docs-only；发布前自查目录。
  • 完整模式文档脚本可联网：沙箱挡住了同源访问，但文档脚本仍可发起网络请求。不信任的 HTML 用默认安全渲染。
  • token 即全部：单 token 模型下，泄漏等同文档全集泄漏。缓解：一键 token rotate；审计可发现异常访问。
  • fail-open 限速：全局失败上限只封当前来源键而非全员，优先保证持有者可用性（防自锁）。256 位 token 空间下爆破不可行，可接受。
  • 发布目录内符号链接竞态（TOCTOU）：检查与读取之间目录被并发改动可绕过包含性检查。信任边界内（能改发布目录的人已有本地权限），不另处置。
